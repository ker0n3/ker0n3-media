Ker0n3 Media privacy policy

Last updated: 26 November 2026.

Ker0n3 Media is a skin and a companion add-on for Kodi. It runs on the user's own device. The project does not operate a server that stores users' accounts, tokens or viewing history.

What is stored, and where

  • Watched history and playback progress: kept in a local database in Kodi's data folder on the device, so the app can show what to continue watching.
  • Account authorisations: if the user links Trakt, Simkl or a debrid account, the access token for that service is stored on the device, in Kodi's data folder, and, only if the user signs in with Google (see below), also in that user's own Google Drive. Passwords are never asked for or stored: linking is done with a code on the service's own website.
  • Cached catalogue data: titles, artwork and lists are cached on the device to make the app faster.

Optional sign-in with Google

The user can optionally sign in with their Google account so that their settings and linked accounts are the same on all their devices. Without signing in, everything works as before and nothing is sent to Google.

  • Permission requested: only drive.file (“See, edit, create and delete only the specific Google Drive files you use with this app”). The app creates a folder called Ker0n3 Media in the user's Google Drive and can only access the files it created there. It cannot see, read or change any other file in the user's Google Drive.
  • What is saved there: the skin's settings (menu, home screen, rows and similar preferences) and the access keys of the accounts the user has linked in the app (debrid services, Trakt, PeLis, MDBList). Settings specific to one device, such as network or audio settings, are not saved.
  • Where it goes: directly from the user's device to the user's own Google Drive. It never passes through, and is never stored on, any server run by the author. The author has no access to it.
  • Google account data: the app reads the email address of the signed-in account only to show the user which account is connected. It does not read contacts, files, email or any other Google data.
  • Limited Use: Ker0n3 Media's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements. The data is used only to provide the sync feature to the user; it is not used for advertising, not sold, and not transferred to anyone else.

What is sent, and to whom

  • Trakt (only if linked): the user's own watched items, playback progress and watchlist changes are sent to and read from that user's Trakt account, to keep their devices in sync. Nothing is read from or written to any other account.
  • Simkl (only if linked): the same, with that user's Simkl account.
  • TMDB and the other services the app queries: the identifiers of the titles being browsed or played, as needed to show information and find streams.
  • Anonymous usage count: once a day the skin sends a random device identifier, the skin variant (TV or touch) and its version to a counter run by the author, to know how many devices use each version. It contains no account data and no viewing data, and the IP address is not stored.

No data is sold or shared with third parties for advertising, and no viewing history leaves the device except to the tracking service the user chose to link.

How long data is kept

Local data stays on the device until the user removes it. Data saved in the user's Google Drive stays there until the user deletes it (see below). The author keeps no copy of users' history, settings or tokens.

Disconnecting and deleting

  • In the app: Settings → Accounts → choose the service → Unlink. This deletes the stored token from the device and the app stops accessing that account.
  • The user can also revoke the app at any time from their Trakt account settings (Connected apps) or the equivalent page of the other service.
  • Google: in the app, Settings → Accounts → Google → Sign out stops syncing; Delete my data from Google removes everything the app saved in the user's Drive. The user can also revoke access at any time at myaccount.google.com/connections, and delete the Ker0n3 Media folder from their Google Drive.
  • Uninstalling the add-on and clearing Kodi's data folder removes the local database and all cached data.

Contact

Questions or deletion requests: open an issue at github.com/ker0n3/ker0n3-media.
